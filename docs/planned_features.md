Планируемые доработки (Planned Features)

Управление пользователями (Admin User Management)
- Удаление пользователей
  - Сейчас: пользователь может удалить только свой аккаунт (`DELETE /api/users/me`).
  - Планируется: администратор с ролью `ROLE_ADMIN` сможет удалять любой аккаунт
    через эндпоинт (`DELETE /api/admin/users/{id}`).

- Сброс пароля
  - Сейчас: пользователь может менять только свой пароль (`PUT /api/users/me/password`).
  - Планируется: администратор сможет сбрасывать пароль любого пользователя (`PUT /api/admin/users/{id}/password`).

Управление задачами (Task Management)
- Редактирование задач
  - Сейчас: пользователь может редактировать только свои задачи.
  - Планируется: администратор сможет редактировать задачи любого пользователя, включая изменение статуса и описания.

- Удаление задач
  - Сейчас: пользователь может удалять только свои задачи.
  - Планируется: администратор сможет удалять задачи любого пользователя.

Примечания
- Первого администратора необходимо создать вручную через базу данных.
- Все административные функции доступны только пользователям с ролью `ROLE_ADMIN`.
- Доступ к административным эндпоинтам будет контролироваться через Spring Security
  и аннотации `@PreAuthorize("hasRole('ROLE_ADMIN')")`.
