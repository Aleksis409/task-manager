Приложение использует JWT-аутентификацию с разделением токенов:
Access Token
- короткоживущий (15 минут);
- используется для доступа к REST API;
- передаётся в заголовке - Authorization: Bearer <access-token>

Refresh Token
- долгоживущий (7 дней);
- хранится в базе данных;
- используется для получения нового access token;
- может быть отозван (logout);
- поддерживается rotation — старый refresh-token инвалидируется при обновлении.

Аутентификация
- Пользователь отправляет /login.
- Получает access + refresh токены.
- Access используется в каждом запросе.
- При истечении access: → /refresh с refresh token.
- При logout refresh-token инвалидируется.

Роли пользователей
- ROLE_USER — обычный пользователь, доступ к своим данным и задачам.
- ROLE_ADMIN — администратор, может изменять роли пользователей.
